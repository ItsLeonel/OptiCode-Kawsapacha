# Ilustraciones originales — Comunidad UX V2

Generadas con la herramienta integrada `image_gen` mediante la habilidad imagegen, a partir del lenguaje visual de las referencias del kit. Son escenas decorativas independientes, sin textos, botones ni datos de usuarios. No se extrajeron controles de las maquetas. Los paisajes y personajes regionales originales del kit se conservaron.

Archivos finales del proyecto, WebP RGB 800×600 (calidad 87):

- `personal.webp`: una persona cultivando su propio jardín; 183.208 bytes.
- `familiar.webp`: una familia cultivando junta; 170.986 bytes.
- `condominio.webp`: vecinos en un patio de edificios compartidos; 211.674 bytes.
- `barrial.webp`: minga de vecinos de un barrio; 210.102 bytes.

Peso conjunto: 775.970 bytes. Los originales generados se mantienen en la ubicación de la herramienta; en el proyecto se emplean estas copias optimizadas. La optimización solo cambia tamaño y formato. La ilustración personal y las escenas familiares/barriales se reutilizan en las tarjetas del paso 3. Responsable utiliza el personaje regional del kit, como ilustración decorativa, no como fotografía de la persona responsable.
